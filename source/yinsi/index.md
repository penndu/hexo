本站（dusays.com，以下简称"本站"）由博主杜朋（以下简称"博主"）运营，非常重视您的个人信息与隐私安全。本声明旨在以清晰、公开的方式说明本站如何收集、使用、存储与保护您的信息。请您在使用本站服务前，仔细阅读本声明。访问或使用本站，即视为您已知悉并同意本声明全部内容。

## 一、信息收集

本站仅在为您提供必要服务所必需的范围内，按以下方式收集信息：

{% radio checked:true 本站 Web 引擎在您访问页面时生成服务器访问日志，记录您的外网 IP 地址、访问时间与请求路径，用于站点运行状态监测与安全防护； %}
{% radio checked:true 您在发表评论时主动提交的昵称信息； %}
{% radio checked:true 您在发表评论时主动提交的电子邮箱地址； %}
{% radio checked:true 您在发表评论时主动提交的网址（可选）； %}
{% radio checked:true 本站使用的 Artalk 评论系统将记录评论者的 IP 地址，用于反垃圾评论与异常行为识别； %}
{% radio checked:true Artalk 评论系统将记录评论者的 User-Agent 浏览器标识信息，用于兼容性分析与反垃圾评论。 %}

## 二、信息使用

本站对所收集信息的使用严格限定在以下目的范围内：

{% radio checked:true 服务器访问日志中的 IP 地址等信息，仅用于站点流量分析与安全防护，且仅博主可见；前端展示仅显示 IP 所属城市，不会暴露您的真实地址。IP 地址由宽带服务商动态分配，不直接关联个人身份。通过分析可了解访问高峰时段、地区分布与内容偏好，以便持续优化访问体验； %}
{% radio checked:true 您提交的昵称仅用于访客身份辨识，全站公开可见；本站不支持匿名评论，但您可使用非实名昵称； %}
{% radio checked:true 您提交的电子邮箱仅用于评论回复通知，仅博主可见，本站不会将其用于邮件营销或向任何第三方提供； %}
{% radio checked:true 您提交的网址（可选）用于博主回访与个人网站展示，全站公开可见。 %}

## 三、信息共享与披露

- 本站**不会**出售、租赁或以任何方式向第三方提供您的个人信息。
- 在符合法律法规规定的情形下，本站可能依据主管部门的合法要求披露必要信息。
- 本站评论系统（Artalk）所记录的 IP 与 User-Agent 数据，存储于博主自主可控的服务环境中。

## 四、Cookie 与外部资源

本站部分功能可能使用浏览器 Cookie 维持会话状态（例如评论者身份识别）。您可通过浏览器设置清除或禁用 Cookie，禁用后可能影响部分功能的正常使用。

本站文章中嵌入的外部链接、图片或视频等资源，由对应第三方网站负责其隐私实践，访问时适用第三方网站的隐私政策。

## 五、信息存储与安全

- 评论相关数据（昵称、邮箱、网址、评论内容）将长期保存于本站数据库，您可联系博主申请删除您本人的评论记录。
- 本站采取合理的技术与管理措施保护信息不被未经授权的访问、篡改或泄露，但请理解：互联网环境并非绝对安全。

## 六、未成年人保护

本站不面向未成年人提供专门服务。如您为未成年人，在使用本站服务前，请由您的父母或监护人代为阅读本声明。

## 七、本声明的更新

本声明可能根据业务调整、法律法规变化等情况适时修订。修订后的声明一经在本页面发布，即视为正式生效，请定期查阅。

## 八、联系我们

如您对本声明或您的个人信息处理有任何疑问、意见或投诉，请通过页面底部的邮箱或博主公开联系方式与博主取得联系。
