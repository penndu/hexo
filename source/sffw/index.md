## 背景介绍

从前身的菜鸟博客，到目前运营的杜老师说，网站已持续运营七年。在这段时间里，杜老师一直对外提供着各类技术支持与配套服务。

除杜老师说不外，杜老师还在运营另一个项目——免费且不限量的外链图床「去不图床」。

杜老师目前就职于中国建设银行总行北京数据中心，担任开放平台部架构实施工程师一职。接触 Linux 近十年，熟练操作各类相关架构，尤为擅长网站环境的搭建、优化与运维，对 WordPress 等开源网站程序亦有深入掌握。

在长期提供技术支持与服务的过程中，杜老师投入了大量的物力与时间成本。随着日常工作压力的增加，杜老师希望能够获得与之匹配的回报，故决定开放一系列收费服务。

需要说明的是，收费服务并非杜老师的主要收入来源，主要目的在于获取部分零花收入，以补贴网站的日常运营成本。目前，杜老师说与去不图床均运行于独立的云主机之上。

## 收费项目

1. **云服务器选购咨询**。如果您不确定应当选购何种配置的主机，可购买此项服务。杜老师具备多年架构与成本规划经验，所推荐的主机配置既可满足您网站的架设需求，亦能为您节省每一分不必要的开支；

2. **云服务器环境架设**。无论 Windows 还是 Linux，杜老师均可为您搭建网站运行环境，让您的网站以最快速度完成上线；

3. **云服务器系统加固**。若您感觉主机存在安全隐患，或频繁遭遇入侵尝试，可选购此项服务。我们会依据实际情况合理配置系统安全机制，让您的服务器无懈可击；

4. **云服务器性能优化**。服务器运行速度日趋缓慢？不必担心，选购此项服务后，杜老师可协助您充分释放服务器性能；

5. **云服务器数据备份**。支持本地备份与异地备份两种方案。杜老师说可为您提供异地备份空间，保障您的数据永不丢失；

6. **云服务器垃圾清理**。Linux 系统空间越用越少，又苦于没有合适的清理工具？选购此项服务，杜老师将亲手为您清理无用文件，让您的服务器轻装上阵；

7. **网站问题排查与解决**。除服务器层面外，网站程序本身的问题同样可以购买服务。杜老师可协助您排查并解决各类网站运行错误，让您的网站恢复正常访问；

8. **网站性能优化**。针对 PHP + MySQL 类站点进行专项优化，减少数据库查询等待时间，加快页面访问速度，为您的访客提供更流畅的使用体验。
