> 自学能力的强弱,基本决定了一个程序员能走多远。在这个知识付费的时代,其实互联网上有大量**优质、免费**的学习资源。本文整理了 15 个我亲身使用、强烈推荐的学习平台,涵盖编程、数据、AI、设计等多个方向。无论你是初学者还是想进阶,都能找到适合的资源。

## 一、官方文档(永远的第一选择)

### 1. MDN Web Docs

[developer.mozilla.org](https://developer.mozilla.org/)

**前端开发的圣经**。HTML、CSS、JavaScript、Web API 的权威文档,Google 都在用。

**特点**:

- 内容权威,持续更新
- 示例代码可直接运行
- 中英文双语
- 涵盖浏览器兼容性数据

### 2. W3School

[w3school.com.cn](https://www.w3school.com.cn/)

中文入门的经典选择,适合零基础。

### 3. 官方文档系列

每个技术栈都有官方文档,**遇到问题时优先查官方**:

- React: [react.dev](https://react.dev/)
- Vue: [cn.vuejs.org](https://cn.vuejs.org/)
- Python: [docs.python.org](https://docs.python.org/)
- Rust: [doc.rust-lang.org](https://doc.rust-lang.org/)
- Go: [go.dev/doc/](https://go.dev/doc/)

## 二、视频学习平台

### 4. 中国大学 MOOC

[icourse163.org](https://www.icourse163.org/)

**国内最权威的免费大学课程平台**。985 高校老师亲授,涵盖计算机、电子、数学、外语等。

**推荐课程**:

- 哈尔滨工业大学 C 语言程序设计
- 浙江大学 Python 程序设计
- 北京大学 算法设计与分析

### 5. B 站(哔哩哔哩)

[bilibili.com](https://www.bilibili.com/)

**B 站是真正的学习网站**。大量优质 UP 主免费分享技术教程。

**推荐 UP 主**:

- **CodeSheep**:编程羊,Java 后端
- **遇见狂神说**:Java、Linux
- **小甲鱼**:Python、C 语言入门
- **黑马程序员**:全套体系课
- **TheCW**:网络安全
- **技术蛋老师**:算法、面试

### 6. YouTube(需科学上网)

**全球最大的学习视频库**。

**推荐频道**:

- **Traversy Media**:Web 开发
- **The Net Ninja**:前后端全套
- **Fireship**:短小精悍的技术科普
- **Academind**:React/Vue/Node
- **Tech With Tim**:Python
- **NetworkChuck**:网络/Linux
- **Computerphile**:计算机科学原理

### 7. Coursera

[coursera.org](https://www.coursera.org/)

**国外名校课程免费学**。旁听免费,获得证书需要付费(可以申请奖学金)。

**推荐课程**:

- Andrew Ng 的 Machine Learning(机器学习入门经典)
- DeepLearning.AI 系列
- Google IT Automation with Python
- IBM Data Science Professional Certificate

### 8. edX

[edx.org](https://www.edx.org/)

哈佛、MIT 等名校课程,质量极高。

### 9. Udacity(部分免费)

[udacity.com](https://www.udacity.com/)

**项目驱动的实战课程**,AI、自动驾驶方向特别强。

## 三、实战练习平台

### 10. LeetCode

[leetcode.cn](https://leetcode.cn/)

**程序员面试刷题必备**。1500+ 算法题,从简单到困难分级,支持多种编程语言。

**刷题建议**:

1. 先按分类刷(数组、链表、二叉树...)
2. 每周坚持 5-10 题
3. 做不出来先看题解,**理解思路**比硬磕重要
4. 重点刷高频面试题

### 11. 牛客网

[nowcoder.com](https://www.nowcoder.com/)

**国内大厂面试真题集散地**,笔试、面试经验分享。

### 12. HackerRank

[hackerrank.com](https://www.hackerrank.com/)

编程练习平台,**适合学习新语言时刷基础题**。

### 13. Codewars

[codewars.com](https://www.codewars.com/)

**趣味编程挑战**。类似游戏闯关,从 8 级到 1 级挑战。

### 14. Codecademy

[codecademy.com](https://www.codecademy.com/)

**交互式编程学习**,边学边练,适合完全零基础。

### 15. freeCodeCamp

[freecodecamp.org](https://www.freecodecamp.org/)

**完全免费的中等长度实战课程**,完成项目可获得认证。

## 我的学习方法论

### 1. 主动学习 > 被动接受

看视频是被动学习,做项目是主动学习。**学完就动手,做出东西才是真的学会了**。

### 2. 带着问题学习

"我想做一个 XX 项目" → 学对应技术 → 做出来。这样学得最快。

### 3. 输出倒逼输入

**写博客/做教程是最高效的学习**。能给别人讲明白,自己才算真的懂。

### 4. 系统化 > 碎片化

不要东一榔头西一棒槌,**先学完一个体系再学下一个**。

### 5. 持续投入 > 短期突击

每天 1 小时坚持一年,远胜周末突击 14 小时。

## 学习路线推荐

### 前端入门(6 个月)

```
HTML/CSS 基础 → JavaScript → ES6+ → Vue/React → 项目实战 → 面试题
```

### 后端入门(6 个月)

```
Java/Go/Python 语法 → MySQL → Redis → Spring Boot/Gin/Django → 项目 → 中间件
```

### 数据分析(3 个月)

```
Excel → SQL → Python → Pandas → 数据可视化(Tableau/PowerBI) → 业务项目
```

## 总结

**学习资源从来不是稀缺品,稀缺的是时间和专注力**。

这 30 个平台里,不需要都用,**选 3-5 个适合自己的深入使用**:

- **零基础**:B 站 + 中国大学 MOOC + 菜鸟教程
- **求职刷题**:LeetCode + 牛客网
- **查文档**:MDN + 官方文档 + Stack Overflow
- **进阶学习**:Coursera + edX + 掘金/CSDN

**坚持每天学一点,一年后你会感谢现在的自己**。
