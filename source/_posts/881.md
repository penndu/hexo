> 工欲善其事,必先利其器。这句话在程序员身上体现得淋漓尽致:选对工具,一天能干完别人三天的活。本文整理了 30 个我日常使用、亲测好用的开发者工具,涵盖代码编辑、终端增强、API 调试、效率提升等方方面面。无论你是前端、后端还是运维,都能从中找到适合自己的工具。

## 一、代码编辑器与 IDE

### 1. Visual Studio Code(免费)

[code.visualstudio.com](https://code.visualstudio.com/)

几乎所有开发者的第一选择。**轻量、扩展丰富、跨平台**。

**必备插件:**

- **Chinese (Simplified) Language Pack**:中文语言包
- **GitLens**:Git 增强
- **ESLint** / **Prettier**:代码规范
- **Live Server**:实时预览
- **Volar**:Vue 3 支持
- **Remote - SSH**:远程开发
- **Code Runner**:运行代码片段
- **TODO Highlight**:高亮 TODO 注释

### 2. JetBrains 全家桶(付费)

[IntelliJ IDEA](https://www.jetbrains.com/idea/)、[PyCharm](https://www.jetbrains.com/pycharm/)、[GoLand](https://www.jetbrains.com/goland/)、[WebStorm](https://www.jetbrains.com/webstorm/) 等。

**优势**:智能提示、重构、调试体验一流。

**技巧**:学生可以申请免费 license;新用户首年优惠;社区版对个人开发者完全够用。

### 3. Cursor(AI 编辑器)

[cursor.sh](https://cursor.sh/)

**AI 编程时代的新王者**。基于 VS Code 二次开发,内置 GPT-4,可以直接用自然语言改代码、写函数。

## 二、终端增强

### 4. Windows Terminal(免费,Windows)

[github.com/microsoft/terminal](https://github.com/microsoft/terminal)

Windows 11 自带,Windows 10 可以装。多标签页、分屏、主题丰富。

### 5. iTerm2(macOS)

[iterm2.com](https://iterm2.com/)

macOS 终端的终极形态,支持分屏、搜索、自动补全。

### 6. Tabby(跨平台免费)

[tabby.sh](https://tabby.sh/)

支持 SSH、Telnet、串口,**内嵌终端 + 文件管理器**。

### 7. Oh My Zsh

[ohmyz.sh](https://ohmyz.sh/)

zsh 配置框架,主题和插件让你的命令行颜值飙升。

**推荐插件:**

```bash
plugins=(
  git
  zsh-autosuggestions    # 自动补全历史命令
  zsh-syntax-highlighting  # 命令语法高亮
  z                      # 目录快速跳转
  extract                # 一键解压
  copypath               # 一键复制路径
)
```

### 8. tmux

终端复用工具,一个窗口开多个面板,断线不丢任务。

```bash
# 常用快捷键
Ctrl+B %    # 垂直分屏
Ctrl+B "    # 水平分屏
Ctrl+B 方向键 # 切换面板
Ctrl+B d    # 脱离 session
```

## 三、API 调试工具

### 9. Postman

[postman.com](https://www.postman.com/)

**API 调试的事实标准**。支持环境变量、自动化测试、Mock Server、文档生成。

### 10. Insomnia

[insomnia.rest](https://insomnia.rest/)

Postman 的轻量替代品,UI 更简洁。

### 11. Apifox

[apifox.com](https://apifox.com/)

**国产之光**。Postman + Swagger + Mock + 文档一体化,中文界面,免费。

### 12. HTTPie(命令行)

[httpie.org](https://httpie.org/)

```bash
# 比 curl 直观得多
http GET https://api.github.com/users/octocat
http POST api.example.com/users name=alice age=30
```

## 工具选择建议

**不要盲目堆工具**。我的经验:

1. **先掌握编辑器的基础快捷键**,能省 30% 时间
2. **终端工具一定要趁手**,每天用 8 小时以上
3. **API 调试工具选一个精通**,别换来换去
4. **笔记工具越早用越好**,积累的红利越大
5. **AI 工具(Cursor/Copilot)现在学还来得及**,未来必备

## 总结

工具是为人服务的,**好的工作流比工具本身更重要**。建议:

- 从这 30 个里**挑 5-10 个**深入使用
- 每个工具**掌握核心快捷键**
- 定期回顾自己的工作流,**找到瓶颈并优化**
- 不要追新,**稳定好用**最重要

**真正的效率来自于流程优化,而非工具堆砌**。希望这份清单能帮你找到适合自己的工具组合,大幅提升日常工作效率。
