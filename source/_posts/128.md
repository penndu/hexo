> Markdown 是一种标记语言，它的优点很多，也被越来越多的写作爱好者广泛使用。有些朋友可能一听到「标记、语言」就觉得很难，实际上它的语法非常简单，常用的符号不过十几个。相比于 HTML，Markdown 显得十分轻量，而且学习成本不高，可以说是轻松掌握、一劳永逸！

<!-- more -->

## Markdown 的优点

1. 专注内容，无需关注排版；

2. 支持 Markdown 的平台越来越多，且能轻松导出多种格式的文件；

3. 可在纯文本中编辑，因此兼容所有文本编辑器；

4. 书写、阅读直观，适合各类写作爱好者。

## Markdown 的工具

在前面的优点中我们已经提到，任何文本编辑器都可使用 Markdown。这里我们推荐网页版的 Markdown 编辑器：这类编辑器在使用 Markdown 语言编辑时，可在右侧实时生成最终效果，方便排版。

当然，本地客户端形式的 Markdown 工具有很多，Windows 上推荐 MarkdownPad 和 MarkPad 两款，大家可以安装试试。

## Markdown 的语法

* 标题：

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

* 列表：

```
* 无序列表
+ 无序列表
- 无序列表
1. 有序列表
2. 有序列表
3. 有序列表
```

* 引用：

```
> 引用内容
```

* 链接：

```
[链接名称](链接地址)
```

* 图片：

```
![图片名称](图片地址)
```

* 粗体：

```
**粗体**
__粗体__
```

* 斜体：

```
*斜体*
_斜体_
```

* 表格：

```
| 对齐 | 左对 | 居中 | 右对 |
| - | :- | :-: | -: |
| 对齐内容 |  对齐内容 | 对齐内容 | 对齐内容 |
| 对齐内容 |  对齐内容 | 对齐内容 | 对齐内容 |
```

* 代码：

````
`一行代码`
```
多行代码
```
````

* 分割：

```
内容
***
内容
```
