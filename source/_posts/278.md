> 许多零基础 Java 开发者刚参加 Java 培训时并不知道 JavaSE/JavaEE/JavaME 三者之间的区别，那我们究竟该学习 JavaSE 还是 JavaEE，还是 JavaME 呢？笔者将以通俗易懂的方式给大家讲解这三者之间的区别。

<!-- more -->

## 三大版本

JavaSE 即 Java 标准版，它是 JavaEE 和 JavaME 的基础，之前也称为 J2SE，主要用于开发 C/S 架构的软件。通俗来讲，它用于开发、部署桌面、服务器以及嵌入设备和实时环境中的应用程序。例如 Java 应用程序开发平台 Eclipse。

JavaEE 即 Java 企业版，之前被称为 J2EE，是在 JavaSE 基础上构建的，用于开发 B/S 架构的软件，主要针对企业应用开发。例如电子商务网站、ERP 系统等。

JavaME 即 Java 微型版，也是以 Java 为基础的，之前被称为 J2ME，它是一套专门为嵌入式设备设计的 API 接口规范，主要用于开发移动设备软件和嵌入式设备软件，主要面向消费类电子产品。例如手机、电视机顶盒、汽车导航系统等。

简单来说，JavaSE 是 Java 的基础，主要针对桌面程序开发；JavaEE 面向企业应用开发；JavaME 则主要针对嵌入式设备软件开发。

## JavaEE 企业版

下面多介绍一些 JavaEE 企业版的相关内容。

JavaEE 在 JavaSE 的基础上进行扩展，增加了一些更加便捷的应用框架。例如我们现在常用的 Java 开发三大框架 Spring、Struts 和 Hibernate，借助这些框架可以轻松地编写出企业级应用软件。

JavaEE 也可以说既是一个框架也是一种规范。说它是框架，是因为它包含了很多开发时常用的组件，例如 Servlet、EJB、JSP、JSTL 等；说它是规范，是因为 Web 应用开发中常用到一些规范模式，JavaEE 提供很多规范的接口却并不实现，而是将这些接口的具体实现细节交给厂商。这样各家厂商推出的 JavaEE 产品虽然内部实现不同，但对外提供的却是统一规范的接口。

例如，我们编写的 JSP 代码，由于大量的显示代码和业务逻辑混杂在一起，彼此嵌套，不利于程序的维护和扩展。当业务需求发生变化时，无论对程序员还是美工而言，都是沉重的负担。为了程序的易维护性和可扩展性，我们需要使用 JavaEE 技术来进行项目开发。
