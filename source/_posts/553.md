## 更换背景

人在家中坐，祸从天上来！因工作关系，杜老师在家中跑测试数据，快到 98% 时突然断电。刚开始以为是电脑高温触发保护自动关机，接着手机收到警告信息提示 NAS 离线，看样子是停电了。杜老师第一时间打算冲出去查看电表是否欠费，还没冲到卧室门口又来电了！通过手机确认电费余额时，突然看到小区群一条信息：楼下电磁门禁坏了，打不开门，物业说可以断了单元电临时开门！来电之后赶紧检查家中的服务器，毕竟杜老师说、去不图床都运行在其上，经过一分钟左右的检测，确保可以正常访问。再次将目光转向 NAS 时，则看到如下画面：

{% image https://cdn.dusays.com/2023/02/553-1.jpg  ratio:1918/866 %}

进入群晖后台管理，点击进入存储管理器，展开存储空间，发现进入警告模式，提示硬盘出现硬性损坏。为了确定损失级别，先进行全面检测，结果很不理想。为了数据安全，只能更换新盘：

{% image https://cdn.dusays.com/2023/02/553-2.jpg  ratio:1918/866 %}

## 硬盘选型

有些小伙伴可能听过红盘、黑盘、蓝盘等等，这些盘的适用环境不同。如红盘一般用于 NAS，具有稳定性好、静音、寿命长等特点。现在硬盘也降价了，所以杜老师斥巨资买了一块东芝 16T 的 NAS 专用盘：

{% image https://cdn.dusays.com/2023/02/553-3.jpg  ratio:1080/1080 %}

## 更换方法

群晖上的坏盘可直接拔出来，理论上不会造成数据丢失。但是稳妥起见，还是先停用坏盘：

{% image https://cdn.dusays.com/2023/02/553-4.jpg  ratio:1918/866 %}

坏盘停用后存储会自动降级，群晖会发出报警音，并有指示灯提醒坏盘所在位。拉出坏盘放入新盘即可：

{% image https://cdn.dusays.com/2023/02/553-5.jpg  ratio:1918/866 %}

重新进入存储管理器中，进行存储修复，其过程会非常漫长：

{% image https://cdn.dusays.com/2023/02/553-6.jpg  ratio:1918/866 %}

## 写在最后

比较庆幸的是，只坏了一块盘，如果两块一起坏了，那杜老师就可以直播撞墙了！

为了安全起见，待存储级别修复完成后，对旧盘做一次全面检测，如有问题尽快更换。

另外为了数据安全、服务稳定，杜老师决定采购 UPS，可实现不间断供电。

小伙伴们如有兴趣，杜老师也可以分享一篇 UPS 的相关文章！
