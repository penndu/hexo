> Microsoft PowerToys 是一组实用工具，可帮助高级用户调整和简化其 Windows 体验，从而提高工作效率。软件能够帮助用户快速切换用户，提供了批量文件重命名工具、文件预览窗格、批量图片处理、通过软件名更快速切换窗口、窗口增强管理、快捷键指南等功能，功能强大齐全。

<!-- more -->

## 保持唤醒

使计算机保持唤醒状态，无需手动管理电源和睡眠设置。运行耗时较长的任务时，这项功能非常有用，可确保计算机不会进入睡眠状态或关闭屏幕。在 PowerToys 设置界面中使用「启用唤醒」开关启用该功能。启用后，应用程序将管理计算机的唤醒状态：

{% image https://cdn.dusays.com/2021/07/359-1.jpg %}

## 颜色选取

颜色选取器是一种系统级颜色拾取工具，通过{% kbd WIN %}+{% kbd SHIFT %}+{% kbd C %}激活。可从当前正在运行的任何应用程序中选取颜色，选取器会自动将颜色按可配置格式复制到剪贴板。颜色选取器内置一个编辑器，其中显示历史取色记录，可用于微调所选颜色并复制不同格式的字符串：

{% image https://cdn.dusays.com/2021/07/359-2.jpg %}

## 窗口管理

FancyZones 是一种窗口管理工具，可用于轻松创建复杂的窗口布局，并将窗口快速放入到这些布局中：

{% image https://cdn.dusays.com/2021/07/359-3.jpg %}

## 文件预览

通过 File Explorer 加载项，可在文件资源管理器中启用预览窗格，以显示 SVG 图标和 Markdown 文件的预览效果。若要启用预览窗格，请在文件资源管理器中选择「视图」选项，然后选择「预览窗格」。

{% image https://cdn.dusays.com/2021/07/359-4.jpg %}

## 图像调整

图像大小调整器是一种用于快速调整图像大小的 Windows Shell 扩展。只需在文件资源管理器中右键单击一下，即可立即调整一张或多张图像的大小：

{% image https://cdn.dusays.com/2021/07/359-5.jpg %}

## 键盘管理

通过键盘管理工具，可重新映射按键并创建自定义快捷键，从而提高工作效率：

{% image https://cdn.dusays.com/2021/07/359-6.jpg %}

## 增强改名

通过 PowerRename 可执行批量重命名、搜索、替换文件名。附带高级功能，如使用正则表达式、面向特定文件类型、预览预期结果以及撤销更改：

{% image https://cdn.dusays.com/2021/07/359-7.jpg %}

## 快速启动

PowerToysRun 可帮助搜索应用并立即启动，只需按{% kbd ALT %}+{% kbd SPACE %}，然后开始键入即可。对于其它插件来说，它是开源且模块化的。现在还包含窗口切换器：

{% image https://cdn.dusays.com/2021/07/359-8.jpg %}

## 热键管理

当用户按下{% kbd WIN %}键超过 1 秒时，会弹出快捷键指南，同时显示当前桌面状态下可用的快捷方式：

{% image https://cdn.dusays.com/2021/07/359-9.jpg %}
