> Listary 是一款实用搜索工具。它能给资源管理器加上许多智能命令，有收藏文件夹，快速打开最近浏览的文件夹，快速显示、隐藏文件扩展名等实用功能。能给日常的收藏和整理文件提高效率。

<!-- more -->

## 键入查找

作为 Listary 强大的搜索功能之一，只需在 Windows 操作系统环境中的几乎任何位置开始键入所需的文件或文件夹名称即可。「键入查找」功能会立即弹出一个列表浏览器窗口，其中显示匹配的文件、文件夹或应用程序列表：

{% image https://cdn.dusays.com/2021/07/360-1.jpg  ratio:1918/866 %}

## 磁盘搜索

磁盘搜索可快速查找系统上每个驱动器中的文件和文件夹。与 Windows 默认需逐个选择驱动器不同，只需打开任意资源管理器窗口或在现有窗口中开始输入，「磁盘搜索」就会以极快的速度在系统所有驱动器中准确定位所需内容：

{% image https://cdn.dusays.com/2021/07/360-2.jpg  ratio:1918/866 %}

## 启动程序

Launch App 是 Listary 用户最喜欢的强大功能之一。连按两次{% kbd CTRL %}键，即可键入要打开的程序名称或简称，单击回车后 Listary 将启动该程序：

{% image https://cdn.dusays.com/2021/07/360-3.jpg  ratio:1918/866 %}

## 快速切换

是否厌倦在大量打开的窗口中反复查找文件？使用 Listary 的快速切换功能，只需按{% kbd CTRL %}+{% kbd G %}即可立即跳转到当前处理文件所在的文件夹：

{% image https://cdn.dusays.com/2021/07/360-4.jpg  ratio:1918/866 %}

## 操作菜单

在任意 Listary 搜索菜单中，只需按右箭头键即可对所选文件或文件夹进行操作，Listary 会立即弹出文件上下文菜单，所有命令触手可及。减少点击次数，意味着更快的工作流程：

{% image https://cdn.dusays.com/2021/07/360-5.jpg  ratio:1918/866 %}

## 收藏历史

Windows 长期缺少一项功能——快速轻松地访问常用文件夹和最近打开的窗口历史记录。现在借助 Listary 的收藏夹和历史记录功能，可以将文件夹加入收藏夹，并通过单击按钮浏览窗口历史记录以便于访问。这就像在您最常用的网络浏览器中使用书签一样：

{% image https://cdn.dusays.com/2021/07/360-6.jpg  ratio:1918/866 %}

## 命令功能

使用 Listary 的命令功能，可通过一组热键命令快速完成打开上一目录、浏览当前目录、复制目录路径、转到应用程序目录、显示隐藏文件、将列表导出为 CSV 等操作：

{% image https://cdn.dusays.com/2021/07/360-7.jpg  ratio:1918/866 %}

## 网页搜索

借助强大的 Listary Keyword 引擎，可直接在 Listary 命令窗口中键入关键词，即可在浏览器中启动任意网站或搜索引擎的搜索窗口：

{% image https://cdn.dusays.com/2021/07/360-8.jpg  ratio:1918/866 %}

## 鼠标配件

就像挥动魔杖访问任何所需内容一样，Listary 鼠标配件让您可以在 Windows 环境中的任意位置双击，打开电源菜单，其中包含所有最常访问的文件、文件夹和磁盘菜单。或者连按两次{% kbd CTRL %}键，即可在屏幕上打开 Listary 搜索工具栏：

{% image https://cdn.dusays.com/2021/07/360-9.jpg  ratio:1918/866 %}
