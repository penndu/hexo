> 上一篇讲日常佩戴，这篇讲进阶。Looki 出厂自带的漫画日记、健康报告只是开胃菜，真正好玩的是：把「今天的记录」变成智能体可以随时读取的上下文。下面五个玩法，都是我自己在跑的。

<!-- more -->

## 出厂功能只是开胃菜

普通用法很简单：挂着，晚上看漫画。

但 App 里那个侧边栏点开，会看到「记忆」「漫画风格」「连接」「Looki 网页版」「数据与隐私」几项。前两个是给普通用户的，后面几个才是玩法入口——**它把「你的今天」做成了一个可被查询的数据源**。

官方开放平台写得很直白：你的生活，也是 AI 需要的上下文。

## 玩法一：把对话列表变成一支常驻团队

{% image https://cdn.dusays.com/2026/12/901-1.webp ratio:1918/866 %}

打开对话页，我这儿常年躺着七八个角色，每个只管一件小事：

| 角色 | 触发方式 | 输出 |
| --- | --- | --- |
| 健康记录助手 | 连续伏案约 3 小时 | 提醒起身、给两个具体动作 |
| 午餐后散步 | 午饭后固定时段 | 附近的公园/路线，按天气改 |
| 场景向导 Agent | 饭点 | 今天换个口味，给店名 |
| 素材自动生产 Agent | 每天上午 | Vlog 素材进度、还差哪些镜头 |
| 当地历史与文化 | 上班时段 | 公司周边可考据的点 |
| 地球Online剧情管理员 | 每日早晨 | 串成「今日刷新」的剧情文案 |

套路其实就一句话：**一个角色，一个触发条件，一份固定格式的输出。**

我自己踩过的坑是「一个 Agent 什么都管」——结果它每天推一堆没用的。拆开之后，每条推送都知道自己该干什么，我也知道哪条该看哪条该划走。

## 玩法二：接进自己的智能体

这是最省事的升级。官方给了三条路，装一种就够：

```bash
# 插件（推荐，一步到位）
npx plugins add https://gitee.com/looki-ai/looki-plugin-cn

# 或者只装技能
npx skills add https://gitee.com/looki-ai/looki-skills-cn.git
```

不想装插件的，直接走 MCP：

```
https://open.looki.tech/mcp
```

装完开个新会话，先问一句「你能通过 Looki 了解我哪些信息」。它会报出日记、瞬间、照片、健康数据这些可读范围，你再决定让它查什么。

注意：技能方式还需要一次浏览器授权登录，别跳过。CLI 认证失败就先跑 `looki auth status`，不行再 `looki login`。

## 玩法三：素材流水线，别堆着不管

{% image https://cdn.dusays.com/2026/12/901-3.webp ratio:1918/866 %}

设备页那张图是真实状态：本地 25.2 GB 已用 533 MB，云端 Looki+ 还有 498.8 GB，圈里那个 163 是待处理的片段数。

这数字涨得比想象快。一天下来一两百段，攒着不处理，云端空间也顶不住。

我的做法是**每天睡前挑一次**：先看缩略图，垃圾直接删，剩下的点「上传并处理」。上传是分批走的，别一次全推，容易卡在中间的进度条上。

## 玩法四：本地优先，隐私自己说了算

{% image https://cdn.dusays.com/2026/12/901-4.webp ratio:1080/1080 %}

「数据与隐私」里能管的东西不多，但够用：哪些同步、哪些留在本地、历史记忆怎么清。

架构上是本地先存、选择性上云，官方说过是端到端加密。我的原则很简单——涉及工作内容、涉及别人的对话，默认不同步；生活琐事无所谓。

另外「连接」里可以挂外部设备，「Looki 网页版」能在电脑上直接翻当天的记录，写东西的时候对着看比手机舒服得多。

## 玩法五：开发向，把记忆变成自己的数据

开放平台除了插件和 MCP，还有 CLI 和 API 文档。官方给的示例挺实在：把出游片段编成绘本、把会议记录整理成纪要、把生活记录备份到本地知识库。

对我这种写博客的，最实用的是**让智能体先读记忆再动笔**。写「这周过得怎么样」，不用再凭空回忆，直接让它把七天的日记摘要拉出来，我再挑细节改成人话。

这一步的关键不是技术，是选对范围：给它三天，不要给三个月；给它具体场景，不要给「我最近怎么样」。

## 三个坑，先替你们踩了

**一、别让 Agent 变成骚扰。** 一天推十几条，一周之内你必然全关掉。控制频率，控制在真正需要提醒的时刻。

**二、语音转写会错名词。** 猫叫被认成人名、菜名被写成同音词都遇到过。重要内容必须人工核一遍，别直接复制进正式文档。

**三、密钥不进聊天记录。** API Key 已经泄露过一回，删了旧的换新的。凡是能被截图的东西，都当它会流出去。

## 写到最后

Looki 官方那句「你的生活，也是 AI 需要的上下文」，我一开始当广告词看。

真用了一个月才明白：AI 什么都知道，就是不知道你昨天中午吃了什么、坐在哪个位置、跟谁聊了什么。这些没人在网上写，也没法搜，只能自己攒。

攒下来的东西，交给智能体用，它才真的像个认识你的人。

至于它能干出什么，取决于你给它派什么活。
