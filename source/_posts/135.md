## 工具介绍

gzexe 是一个用于压缩脚本文件的小工具。执行压缩过的脚本时，文件会自动解压后继续执行，效果与一般可执行文件相同。

但压缩后的文件内容会变得面目全非，起到一定的混淆效果，因此我们常借此命令对脚本进行加密！

## 脚本加密

```
gzexe FILENAME
```

注意：使用 `gzexe` 加密后，会在文件所在目录生成一个文件名后加 `~` 的文件，该文件即为加密前的原文件！

## 脚本解密

```
gzexe -d FILENAME
```

注意：使用 `gzexe` 解密后，文件名后带有 `~` 的原文件并不会自动删除，记得手动清除。
