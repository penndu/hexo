> GitHub 上有小伙伴说通过群晖的 Docker 安装 Lsky Pro 图床失败，杜老师看到问题后自己试了一下，并没有复现，整理一下操作步骤，给有需要的小伙伴作参考！

<!-- more -->

## 写在前面

Lsky Pro 图床程序支持多种数据库类型，如常见的 MySQL/SQLite 等，本文以 SQLite 为例，记录在群晖 Docker 上的部署过程。

杜老师的群晖型号为 DS720plus，系统版本为 DSM 7.1-42661 Update 1，Docker 套件的版本为 20.10.3-1306。

## 操作步骤

首先进入 Docker 注册表，搜索关键词 `HalcyonAzure/lsky-pro-docker`，在搜索结果中直接下载：

{% image https://cdn.dusays.com/2022/05/461-1.jpg  ratio:1918/866 %}

映像约 800M 左右，下载完成后启动。网络默认选 bridge 即可：

{% image https://cdn.dusays.com/2022/05/461-2.jpg  ratio:1918/866 %}

下一步后，记得勾选「启用自动重新启动」：

{% image https://cdn.dusays.com/2022/05/461-3.jpg  ratio:1918/866 %}

设置访问端口，如不设置，也可使用自动生成的端口，对图床使用没有影响：

{% image https://cdn.dusays.com/2022/05/461-4.jpg  ratio:1918/866 %}

设置目录映射，将群晖本地文件夹映射到 `/var/www/html`，最后确认完成：

{% image https://cdn.dusays.com/2022/05/461-5.jpg  ratio:1918/866 %}

通过浏览器打开该容器访问地址，在设置数据库时选择 SQLite 就可以了：

{% image https://cdn.dusays.com/2022/05/461-6.jpg  ratio:1918/866 %}
