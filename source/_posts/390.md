> Vercel 虽是免费的，但因为其服务器在国外，常会遇到访问不稳定的问题。最近良心云推出了个人站点扶持计划，不少已备案的小伙伴转到了国内托管，今天就分享下通过 Webify 部署 Hexo。

<!-- more -->

## 服务介绍

CloudBase Webify 为您的 Web 应用提供一站式托管服务，支持静态网站、动态 Web 服务等各种类型的 Web 应用，并提供默认域名、可自定义域名、安全证书、CDN 加速等功能，全面提升 Web 应用的性能和安全性。此外还提供基于 Git 的工作流和自动部署流程，加速开发与部署体验。

可将博客、论坛、官网等任意形式的个人站点部署到 Webify，并可申请获得扶持代金券，实现零成本网站托管。

## 在线部署

进入良心云 Web 应用托管页面，点击页面中的「新建应用」：

{% image https://cdn.dusays.com/2021/10/390-1.jpg %}

在右侧从模板创建中找到 Hexo：

{% image https://cdn.dusays.com/2021/10/390-2.jpg %}

选择源码托管平台，并设置托管仓库名，然后点「下一步」：

{% image https://cdn.dusays.com/2021/10/390-3.jpg %}

在框架预设中选择 Hexo 项，然后点击「部署应用」：

{% image https://cdn.dusays.com/2021/10/390-4.jpg %}

服务开始部署应用，待页面提示发布成功后即可正常访问博客：

{% image https://cdn.dusays.com/2021/10/390-5.jpg %}

服务会免费赠送一个访问地址，不过该域名较长不易记忆，可自行添加域名，且支持 SSL：

{% image https://cdn.dusays.com/2021/10/390-6.jpg %}
