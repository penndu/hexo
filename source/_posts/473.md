## 写在前面

杜老师的电脑自带内存是两条金士顿 16G 3200MHz，原厂内存价格较高，所以到某东上买了同品牌同频率的：

## 出现问题

插上新内存后，发现新内存频率仅有 2400MHz，自带的内存也降为 2400MHz。开始以为是新内存问题，杜老师在另一台电脑上测试发现新内存确实是 3200MHz。

询问官方客服后了解到，刃 7000P 仅支持 JEDEC 内存，而杜老师买的是市面上常见的 XMP 内存，这种内存需设置超频才能达到 3200MHz「JEDEC 和 XMP 的区别请自行搜索，如有不理解，欢迎留言交流」

内存主频和 CPU 主频一样，用来表示内存的速度，代表该内存所能达到的最高工作频率。内存主频以 MHz 为单位计量。主频越高，在一定程度上代表着内存所能达到的速度越快，同时决定着该内存最高能在何种频率下正常工作。

决定内存性能的核心因素有内存容量、带宽、频率。在同代内存、相同容量条件下，内存频率越高性能越好。如果是不同代内存，例如 DDR3 和 DDR4，相同容量下 DDR4 的内存性能必然优于 DDR3。毕竟 DDR4 的频率均在 DDR3 之上，新一代内存在带宽上也有所升级，功耗更低。

其实 2400MHz 对普通用户来说很够用了，但杜老师对电脑的性能要求较高。

原厂内存不仅价格贵，还经常断货。既然超频可以解决，为何不尝试一下呢？

## 解决方法

安装好工具后，打开时会出现警告提示。因为超频都是通过加压方式实现的，可能会对硬件有所影响，但这款官方超频工具十分安全，点击「确定」即可：

{% image https://cdn.dusays.com/2022/06/473-2.jpg %}

为方便用户使用，工具提供基础视图和高级视图两种模式，如需操作内存，需点击进入高级视图：

{% image https://cdn.dusays.com/2022/06/473-3.jpg %}

在高级视图左侧调整运行模式，这里选择 Creator Mode。在内存控制右侧，点击「已排除项」即可切换成「已包含」「后面的自动推送和手动推送建议默认」最后点击下方「应用」，按提示重启系统：

{% image https://cdn.dusays.com/2022/06/473-4.jpg %}

重启后打开任务管理器，切换到「性能」栏的「内存」项，即可看到频率已变为 3200MHz：

{% image https://cdn.dusays.com/2022/06/473-5.jpg %}
