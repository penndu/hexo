> 为了方便更新文章，杜老师使用 Docker 搭建 GitLab 做文章管理，后期迁移到群晖上，并做了外网映射。迁移后需要修改 GitLab 的域名及端口，今天分享下修改方法。 

<!-- more -->

## 地址修改

查询绑定地址或 IP 的命令为：

```
grep ^external_url /etc/gitlab/gitlab.rb
```

如需修改绑定地址，则编辑文件/etc/gitlab/gitlab.rb：

```
external_url http://gitlab.dusays.com;
```

## 端口修改

如需修改端口，则编辑文件 /etc/gitlab/gitlab.rb：

```
nginx['listen_port'] = 8080
```

记得取消注释。最后提醒：任何配置修改完后，都需重新生成配置：

```
gitlab-ctl reconfigure
```
