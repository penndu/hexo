> rpm 原本是 Red Hat Linux 发行版专门用来管理 Linux 各项套件的程序，由于它遵循 GPL 规则且功能强大易用，因而广受欢迎，并逐渐被其它发行版所采用。rpm 套件管理方式的出现让 Linux 易于安装与升级，间接提升了 Linux 的适用度。

<!-- more -->

## 命令介绍

rpm 是通过数据库记录的方式将所需套件安装到 Linux 主机的管理程序，即 Linux 系统中存在一个关于 rpm 的数据库，记录了已安装包之间的依赖关系。rpm 包是预先在 Linux 主机上编译好并打包的文件，安装起来非常快捷。

rpm 软件包也称为二进制包，是已编译好的软件包。其优点是管理系统简单，仅通过几个命令即可实现包的安装、升级、查询、卸载，安装速度比源码包快得多；其缺点是已经编译，无法查看源代码，功能选择不如源码包灵活，且需要解决依赖关系。

## 选项列表

选项列表如下：

| 选项 | 作用 |
| - | - |
| -a | 查询所有套件 |
| -b | 设置套件打包的完成阶段并指定套件文件的名称 |
| -c | 列出配置文件，需配合 -l 参数使用 |
| -d | 列出文档文件，需配合 -l 参数使用 |
| -e | 删除指定套件 |
| -f | 查询拥有指定文件的套件 |
| -h | 套件安装时显示进度标记 |
| -i | 显示套件相关信息 |
| -i | 安装指定的套件文件 |
| -l | 显示套件文件列表 |
| -p | 查询指定的套件文件 |
| -q | 使用询问模式，遇到任何问题时先询问用户 |
| -R | 显示套件的依赖关系信息 |
| -s | 显示文件状态，需配合 -l 参数使用 |
| -U | 升级指定的套件文件 |
| -v | 显示指令执行过程 |
| -vv | 详细显示指令执行过程，便于排查错误 |
| --addsign | 为指定套件添加新的签名认证 |
| --allfiles | 安装所有文件 |
| --allmatches | 删除匹配指定套件所包含的所有文件 |
| --badreloc | 发生错误时重新配置文件 |
| --buildroot | 设置产生套件时作为根目录的目录 |
| --changelog | 显示套件更改记录 |
| --checksig | 校验套件的签名认证 |
| --clean | 完成套件打包后，删除打包过程中建立的目录 |
| --dbpath | 设置存放数据库的目录 |
| --dump | 显示每个文件的验证信息，需配合 -l 参数使用 |
| --excludedocs | 安装套件时不安装文档 |
| --excludepath | 忽略指定目录里的所有文件 |
| --force | 强行置换套件或文件 |
| --ignorearch | 不验证套件文件的结构正确性 |
| --ignoreos | 不验证套件文件的结构正确性 |
| --ignoresize | 安装前不检查磁盘空间 |
| --includedocs | 安装套件时一并安装文档 |
| --initdb | 确认存在可用的数据库 |
| --nodeps | 不验证套件间的依赖关系 |
| --nofiles | 不验证文件的属性 |
| --percent | 安装套件时显示完成百分比 |
| --pipe | 建立管道，将输出结果转为指定指令的输入数据 |
| --prefix | 重新配置文件时，将文件放到指定目录下 |
| --provides | 查询该套件所提供的兼容能力 |
| --querytags | 列出可用于文件头格式的标签 |
| --rcfile | 使用指定配置文件 |
| --rebuild | 安装原始源码套件，重新生成二进制套件文件 |
| --rebuilddb | 基于现有数据库重建一份数据库 |
| --relocate | 将本来放到原目录下的文件放到新目录 |
| --replacefiles | 强行置换文件 |
| --replacepkgs | 强行置换套件 |
| --requires | 查询该套件所依赖的兼容能力 |
| --resign | 删除现有认证，重新生成签名认证 |
| --rmsource | 完成套件打包后删除原始代码 |
| --rmsource | 删除原始代码和指定的文件 |
| --root | 设置作为根目录的目录 |
| --setperms | 设置文件权限 |
| --setugids | 设置文件拥有者和所属群组 |
| --short-circuit | 直接跳过指定的完成阶段 |
| --target | 设置产生套件的目标平台 |
| --test | 仅作测试，不真正安装套件 |
| --verify | 该参数的效果与指定 -q 相同 |
| --version | 显示版本信息 |
| --whatprovides | 查询该套件对指定功能特性所提供的兼容能力 |
| --whatrequires | 查询该套件对指定功能特性所需的兼容能力 |
