> 大部分用户可能不知道 Windows 10 系统下有一个 S 模式，什么是 S 模式？S 模式中的 Windows 10 是一个受限制的锁定 Windows 操作系统。如果想了解更多 S 模式，不妨看看下面的详细内容吧！

<!-- more -->

## 模式介绍

微软在安全性、速度和稳定性上投入了大量精力。由于 Windows 10 只能从商店运行应用程序，因此来自网络的恶意软件将无法运行。

用户无法从网上随意安装应用程序，因此这些程序也就无法安装启动任务，不会减慢启动过程，也不会隐藏在后台并生成垃圾文件。

S 模式也推动了 Bing 搜索引擎的发展。在 S 模式下，Edge 浏览器使用 Bing 作为默认搜索引擎。

用户无法将 Edge 的默认搜索引擎更改为 Baidu 或其它任何搜索引擎，除非先离开 S 模式。S 模式下的 Windows 10 同样无法通过注册表编辑器直接访问 Windows 注册表。

不能使用像 PowerShell 这样的命令行工具，但其它各种开发工具不受限制。如果要运行的所有应用程序在 Microsoft Store 中均可用，那么 S 模式是更安全的体验。

这便是微软最初为学校推出 S 模式的原因。S 模式可运行 Microsoft Edge、Microsoft Office 以及 Store 中的其它应用，包括 QQ 和微信等。

这有点像 iPad 上的 iPadOS 操作系统，只允许从 App Store 安装应用程序；而 S 模式则限制只能使用 Microsoft Store 中提供的 Windows 应用程序。

Windows 10 的 S 模式是可选择的。大多数 Windows 10 个人电脑都预装标准的 Windows 10 家庭版或 Windows 10 专业版操作系统，可从任何地方运行软件。

带有 S 模式的电脑会在产品规格中注明使用的是"S 模式下的 Windows 10 家庭版"或"S 模式下的 Windows 10 专业版"。即使在 S 模式下购买 PC，也可以免费离开 S 模式。

切换本身不需要任何费用，但这是一次性决定：一旦将 PC 从 S 模式退出，便无法再将其重新置于 S 模式。

## 模式检查

依次前往「设置 — 系统 — 关于」，可以检查当前是否正在使用 S 模式。在「关于」页面上向下滚动到 Windows 规格部分。如果在版本条目右侧看到「S 模式」字样，则表示正在使用 S 模式。

目前最常见的 S 模式电脑就是微软的 Surface Go 系列，该系列对应的则是苹果 iPad 系列，二者所搭载的系统均运行 S 模式。

## 模式选择

应该购买带 S 模式的电脑吗？因为离开 S 模式既容易又自由，所以购买 S 模式附带的电脑并没有任何不利之处。

即使不需要 S 模式，也可轻松切换。比如微软只以 S 模式销售 Surface Laptop。

即使想要一台运行标准版 Windows 操作系统的 Surface Laptop，也可以购买后再免费从 S 模式中退出。

应该在 S 模式下使用吗？S 模式虽然听起来有诸多限制，但只要您只需要基本的 Microsoft Edge、Microsoft Office 应用程序以及 Microsoft Store 中提供的其它应用程序，不妨尝试在 S 模式下使用 PC。S 模式的限制恰好提供了针对恶意软件的额外保护。

在 S 模式下运行的 PC 也适合年轻学生、仅需少量应用程序的商用 PC 以及经验较少的计算机用户。

当然，如果需要使用商店中不可用的软件，则必须离开 S 模式。不过可以先在 S 模式下使用一段时间，体验一下效果。

## 模式退出

请先记住：尽管可以随时离开 S 模式，但选择离开 S 模式是一个永久的决定。

一旦离开了 S 模式，便永远无法再回到 S 模式，系统将使用标准的 Windows 10 家庭版或 Windows 10 专业版操作系统。

不过，您仍可以选择仅允许来自 Windows 10 应用商店的应用。在运行 S 模式的 Windows 10 电脑上，依次打开「设置 — 更新 — 激活」。

在"切换到 Windows 10 家庭版"或"切换到 Windows 10 专业版"部分中选择「转到 Microsoft Store」。

在 Microsoft Store 中显示的「退出 S 模式」页面上，选择「获取」按钮。

等待页面上显示确认消息后，就可以安装来自 Microsoft Store 之外的应用了。
