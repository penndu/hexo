> Linux 可以通过命令实现各种操作，但有些命令十分危险，运行轻则数据丢失，重则导致系统宕机。今天杜老师为大家总结 Linux 系统 3 个最危险的命令！

<!-- more -->

## 删除命令

```
rm -rf /*
```

注意：`rm` 用于删除文件；`-r` 表示递归删除目录；`-f` 表示强制删除且不提示；`/` 表示根目录；`*` 表示目录下的所有文件及子目录。

## 循环调用

```
:() { :|:& }; :
```

注意：这是一个 fork 炸弹的示例。其原理是定义一个函数，使其调用自身两次，一次在前台、一次在后台。它会反复执行下去，直至系统崩溃。

## 写入操作

```
dd if=/dev/random of=/dev/sda
```

注意：上述命令会向块设备 `sda` 写入随机数据，从而擦除其中的数据。一旦执行，您的系统将陷入混乱，且可能进入不可恢复的状态。

## 文章总结

请不要在您或他人电脑的 Linux 终端中执行以上任何一个命令。

如想测试，请在虚拟机中运行。
