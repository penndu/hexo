> fdisk 是用于创建和维护分区的命令，兼容 DOS 类型的分区表，以及 BSD 或 SUN 类型的磁盘标签。今天杜老师为大家讲解一下该命令的使用！

<!-- more -->

## 命令介绍

从本质上说，fdisk 对硬盘进行分区的过程就是对硬盘的一种格式化。当我们创建分区时，就已经设置好了硬盘的各项物理参数，并指定了硬盘主引导记录和引导记录备份的存放位置。

而文件系统及其他操作系统管理硬盘所需的信息，则是通过后续的高级格式化（即 mkfs 命令）实现的。

打个形象的比喻：分区好比在一张白纸上画方框，格式化好比在方框里打格子，安装各种软件则好比在格子里写字。

分区和格式化就相当于为安装软件打基础，实际上它们为电脑在硬盘上存储的数据起到标记定位的作用。

## 命令格式

查看磁盘分区列表：

```
fdisk -l
```

指定硬盘分区：

```
fdisk /dev/sdX
```

## 菜单列表

列表如下：

| 指令 | 作用 |
| - | - |
| m | 显示菜单、帮助信息 |
| a | 活动分区标记、引导分区 |
| d | 删除分区 |
| l | 显示分区类型 |
| n | 新建分区 |
| p | 显示分区信息 |
| q | 退出但不保存 |
| t | 设置分区类型 |
| v | 进行分区检查 |
| w | 保存修改 |
| x | 扩展应用，高级功能 |
