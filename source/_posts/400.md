> 没经历过不会懂得，只有运营公益图床，才会知道公益图床多么难做。除了高额的运营成本外，还有个更大的敌人——违禁图片。

<!-- more -->

## 图片审核

现如今不管是手机用户还是电脑用户，遇到违禁图片时都习惯随手举报。而由于人工智能的存在，审核速度越来越快，轻则该图无法访问，重则直接封禁域名。

这种情况对于图床而言是致命的打击。何况去不图床托管在云服务商，如果云服务商的审核机制检测到存储内有违禁图片，将直接封禁账号。

为避免用户上传违禁图片，去不图床启动审核机制：每日 0 点 10 分自动审核前一日上传的所有图片，如有违禁图片，将于次日 9 点 30 分前集中删除。

未选择实时审核是为了不影响用户的上传速度，但这也导致一张违禁图片至少有 9 小时的外链期。为彻底杜绝违禁图片，去不图床不得不调整运营政策。

## 投诉举报

前几日收到存储机房告警信息，提示有几张图产生了巨大的外链流量，结果一看全是违禁图片。杜老师在第一时间删除了这些违禁图，并调取了引用页面信息，最后将这些网站一并举报：

## 应对政策

这种情况已不止一次出现。为此，去不图床将停止访客上传功能，必须注册用户才可上传图片。为防止账号滥用，之后将采用账号付费形式运营。暂定价格如下：

| 价格 | 容量 |
| - | - |
| 2 元 | 100 兆 |
| 10 元 | 1024 兆 |
| 16 元 | 2048 兆 |
| 24 元 | 3072 兆 |
| 28 元 | 4096 兆 |
| 30 元 | 5120 兆 |

## 替代方案

存储费用暂且不提，又拍云的流量费为 0.29 元/GB，图片审核费为 1.8 元/千次，所以图床每日产生的账单对杜老师来说都是不小的压力，付费使用也是不得已而为之。

如果不想付费使用图床，也可选择其它替代方案。在杜老师的博客圈子中，少数小伙伴会选择用 GitHub 托管图片：上传到 GitHub 的图片可通过 jsDelivr 链接加速访问，而 jsDelivr 有国内节点，访问速度还是非常快的。

这里仅为部分用户提供一些解决思路，并非推荐！GitHub 和 jsDelivr 已发出声明，禁止使用其作为托管图片的平台，一旦发现则会封禁账号。杜老师在此提醒：务必做好数据备份。

最后感谢小伙伴们对去不图床的理解和支持，图床作者七月也在持续更新程序，期待为大家提供更好的服务！
