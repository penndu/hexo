> 新版本去不图床使用了全新底层框架，API 的管理方式也随之改变，本文介绍新版本去不图床 Token 的获取与清空方法，方便用户使用 PicGo 等工具上传、管理图片。

<!-- more -->

## 获取

新版图床在获取 Token 时需要使用 HTTP 请求工具，为方便大家使用，杜老师已填好大部分信息。请访问下面的地址，修改其中的 EMAIL「如已修改密码，请将 12345678 改为新的密码」

{% psw https://getman.cn/?s=91b1a0b3c8d3c832d237421aaf181a96 %}

填写好相关信息后，点击对勾提交请求，即可看到返回的 Token：

{% image https://cdn.dusays.com/2022/04/454-1.jpg %}

## 清空

新版支持多 Token，您可多次申请并应用在不同平台上。但需注意，一旦 Token 不慎泄露，暂不支持自行取消对应 Token 的授权，您可以选择联系杜老师，或手动清空所有 Token。请访问下方地址，修改其中的 EMAIL「如已修改密码，请将 12345678 改为新的密码」

{% psw https://getman.cn/?s=4d20a20fae3ca1bb18e74f20082e0049 %}

填写好相关信息后，点击对勾提交请求，即可看到返回信息：

{% image https://cdn.dusays.com/2022/04/454-2.jpg %}
