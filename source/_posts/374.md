## WordPress 的优缺

WordPress 的优点可真不少，首先是用户基数大。据不完全统计，每十个网站就有三个由 WordPress 创建，而且不全是博客。这就带出其第二个优点：扩展性强，几乎所有的功能需求都可以通过插件实现，甚至有大牛可直接上手修改代码。由于用户基数大，也有不少前端工程师为其开发模板，所以我们在 WordPress 平台上可以很容易找到心仪的模板。

再说一个优点——也是因为用户基数大——技术支持丰富。随便在博客圈里问问，都能解决当下问题，省时省力。

夸赞完了该说说缺点了。第一个缺点是臃肿。为了让它更具扩展性，作者为其加入了不少函数，其中很多都是普通用户用不到的，所以代码十分臃肿。其次是效率问题：WordPress 不仅耗费服务器资源，而且执行效率低下。作为一个依赖 MySQL 数据存储的程序，竟不做 SQL 优化，在服务器上经常能看到关于 WordPress 的慢查询语句。而且悄悄地说，MySQL 的临时缓存加速对其无效——别问为什么。

最后一个缺点是用着用着出问题。你本想安静地写篇文章，却经常因为程序、插件或模板升级而遇到各种问题：轻则无法正常使用，重则数据丢失，你的时间都浪费在处理这些问题上。导致杜老师放弃 WordPress 的最主要原因是它过于重量级——700 篇博客竟需要 4H8G 的配置才能带动，也可能是因为杜老师没优化好。

## Hexo 的优缺

轻量部署、成本低、定制性强、安全性高。

轻量部署：Hexo 不需要复杂的网站运行环境，只需支持 Node.js 即可，几条命令就能完成 Hexo 的安装与使用。

成本低：如果只是为了记录，对服务端要求并不高，可选择免费网站托管平台。如想自建托管平台，也不需要太高的服务器配置，入门级云主机即可承载高并发。

定制性强：Hexo 的外观及功能大多依赖于模板，而模板的使用及修改都很简单，并不像 WordPress 那样必须掌握 PHP 语言。

安全性高：生成的页面为 HTML 格式，无动态文件产生，不会出现 SQL 注入等安全问题。

功能有限、模板有限、容易出错、需要扩展。

功能有限：既然是 HTML，没有数据库支持，功能方面必然有限。

模板有限：相比 WordPress，Hexo 的模板数量不多，而且大多是个人作者，不像 WordPress 有企业级模板作者。

容易出错：Hexo 本身还好些，但其依赖的 Node.js 可能会报错，而且某些报错比较神奇，同样的环境在有人那里没问题，在有人那里就会报错。

需要扩展：很多功能都依赖第三方服务，例如评论等。

## 目前状况

上述缺点其实还好，毕竟玩博客这么久，早已没有折腾的心，就想安静地写点东西。且目前 Hexo 具备的功能可以满足杜老师需求，所以对 Hexo 还是比较满意。

只是随着文章数量增多，生成页面的时间越来越长，期间优化过很多次「升级版本、修改参数」均未能提高效率，所以想换一个程序。

## 我的需求

希望这款程序可以将 .md 文件直接转换为博客文章，毕竟 .md 的备份和修改都很方便。如果可以，最好自带评论系统，依赖第三方整合性较差。而且 Hexo 目前支持的第三方评论工具大多需要将数据存放在其它位置，这种动态数据无论备份还是管理都很麻烦，数据掌握在自己手里才更放心。

之前有小伙伴推荐过 Ghost 以及 Hugo 等，但测试效果不尽人意，期待有天能遇到心仪的博客程序，也欢迎大家推荐！
