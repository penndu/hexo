> 大家平时通过域名访问 Web 时，都需要经过 DNS 缓存服务器将域名解析成 IP 地址，才能正常访问网站。网络中的公用 DNS 缓存服务器很多，杜老师今天也搭建了一台 DNS，为什么要「多此一举」？看完这篇文章您就懂了！

## 常规解析

平时我们通过域名访问网站时，需要先将请求发送到 DNS 缓存服务器，DNS 会将其解析到对应的 IP，然后将结果返回给我们，我们再通过该 IP 地址访问网站。

DNS 缓存服务器需要做到两点：第一就是高速，能为我们提供快速的解析请求；第二就是准确，能够返回正确的结果。

## 杜老师版

杜老师提供的 DNS 缓存与常规版本不同，在 DNS 解析结果返回前，添加了一个过滤器，这个过滤器会屏蔽大量广告解析，这样大家在访问网站时，就能屏蔽一部分广告。

其原理是：很多网站由「正文」和「广告」两部分构成，而广告内容都使用独立域名。我们在解析该类域名时，如果返回错误的结果，广告自然就无法显示了。

## 设置方法

只需要将电脑的 DNS 改为 `106.12.217.238` 就行了「相应工信部的政策，非运营商不得对外提供解析服务」
