> 回家那天，门口放着一个快递盒子——面单没写是什么寄来的，只是个普通的纸箱。拆开才知道是礼盒，确实是小小 API 站长寄来的中秋礼物。

## 门口那个纸箱

那天我回家，门口放着一个快递盒子——**面单上没写是谁寄的**，所以我拆开之前还以为就是个普通快递。外箱上能看到"小心开拆 勿用刀划"、"稻香村集团旗下品牌"这样的字样。

{% image https://cdn.dusays.com/2026/09/889-1.jpg  ratio:1918/866 %}

之后问了站长，才确认这是小小 API 那边寄来的中秋礼物。

## 礼盒长得挺用心

拆开外箱，是稻香村的礼盒。整体是青色主调，搭一条紫色的"低糖心意"色带，金色章印写着"蔗糖含量减 35%"，右下角标着"净含量 510 克"。

{% image https://cdn.dusays.com/2026/09/889-2.jpg  ratio:1918/866 %}

礼盒印刷比较细——骑车的人、跑步的人、月兔、亭子这些小元素排在一起，传统节气感和现代运动感搭得挺协调。单看外盒就觉得是有花心思的，不是那种群发批量采购的味道。

## 拆开里面是这样

打开礼盒，里面是若干独立包装的月饼。颜色和造型各有不同，从图里能看到的是 4×3 排布、12 块可见的样子，每一块都有金色独立包装。

{% image https://cdn.dusays.com/2026/09/889-3.jpg  ratio:1918/866 %}

## 一年前的那篇同题博文

一年前我写过一篇 [《免费、快速、稳定的公益 API 平台推荐》](https://dusays.com/posts/755/)，那次是从技术维度系统介绍过小小 API——接口多、响应快、站长维护用心这些我都记下了。今年没做新的对照评测，但借这件事再把它拿出来提一下。具体功能、性能、稳定性以官网最新公告为准。

## 小小 API 的近况（公开信息）

按 [xxapi.cn](https://xxapi.cn/) 首页公开内容整理：

- **小小 API**，定位专业的 API 服务平台
- 自述技术架构：分布式部署、HTTPS、签名校验、IP 白名单、SDK 工具
- 合作伙伴页面里能找到「杜老师说」

**有一点变化**：新闻动态显示 **2026-06 汇率接口已启用收费套餐**（日/月/季/年/次数）。这和早期"完全免费"的说法不一样了，调用前最好去看一眼官方公告。
