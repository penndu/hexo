> 上周办公室桌上突然多出一个牛皮纸盒——拆开一看，是小小 API 站长寄来的中秋月饼礼盒。借着这份人情，把一年前写的 [《免费、快速、稳定的公益 API 平台推荐》](https://dusays.com/posts/755/) 拿出来再聊一次：一年后的小小 API 还值得用吗？我又试了两个月，**结论是：值得**。

## 一盒意料之外的中秋礼

9 月 19 号下午，同事把一个牛皮纸盒放到我桌上，说"杜老师你的快递"。

我以为是哪个甲方寄的样品，扫了一眼面单才发现——寄件人是**小小 API 站长**，备注栏写着"中秋快乐"四个字。

{% image https://cdn.dusays.com/2026/09/889-1.jpg  ratio:1918/866 %}

牛皮纸盒侧面印着"套装勿拆 谢谢配合"，紫红色封贴上写着"低糖心意"四个字。包装不算奢华，但能看出用心——这是一种**"我把你当朋友而不是客户"**的态度。

比起那些中秋群发"月饼兑换券"的商业 API 厂商，这份手作的诚意更让我想写点什么。

## 礼盒打开，先被设计打动

拆开外箱，里面是稻香村集团出品的"低糖心意"中秋礼盒，510 克，蔗糖含量减 35%。

{% image https://cdn.dusays.com/2026/09/889-2.jpg  ratio:1918/866 %}

整个礼盒的设计让我这个写博客的人都有点汗颜：

- **配色**：青色主调 + 紫红色"低糖心意"色带，传统又不土
- **插画**：骑自行车的女孩、跑酷女孩、月兔、亭子飞燕——把传统元素和现代运动场景结合
- **细节**：底纹是"低糖健康"主题的月饼文字环绕

一个 API 站长的审美能做到这个程度，我只能在心里默默点个赞。

## 16 种口味，月饼本身没让人失望

礼盒拆开是 **4×4 共 16 块月饼**：紫薯、抹茶、桃山皮、蛋黄莲蓉、奶黄流心、五仁、豆沙、枣泥、玫瑰、桂花、椰蓉、奶酪、核桃、芝麻、莲蓉、板栗。

{% image https://cdn.dusays.com/2026/09/889-3.jpg  ratio:1918/866 %}

站长后来在微信里说，这是他今年**试吃了 7 家月饼厂商**才定下来的。吃完之后我得说——这份心意是真的实打实。

我个人最爱桃山皮和奶黄流心（不过这两块一开盒就被同事抢光了 😅）。最关键是**第二天没有"齁嗓子"的感觉**，35% 蔗糖减单确实不是噱头。

## 一年前的那篇推荐文

借这份人情，正好把 2024 年 10 月写过的 [《免费、快速、稳定的公益 API 平台推荐》](https://dusays.com/posts/755/) 翻出来对照一下。

|---|---|---|
| 接口数量 | 60+ | **90+** |
| 平均响应时间 | 80ms | **50ms** |
| 文档完整度 | 良好 | **更好（新增 5 种语言 SDK）** |
| 维护频率 | 周更 | **周更 + 实时响应 issue** |
| 站长活跃度 | 工作日 | **工作日 + 周末** |

可以看出来，**站长是真把这件事当副业在认真做**，而不是搞一个"开源就躺"的项目。这一点在 2025 年一票"开源变收费"的浪潮里尤其显得可贵。

## 为什么这次"复推"

不是因为月饼好吃（虽然确实好吃），而是这一年里我又**实实在在用了两个月**——分别在两个项目里集成了小小 API 的几个接口：

1. **天气接口**：稳定跑了 2 个月 0 故障；
2. **IP 归属地查询**：每天 10w+ 调用量，没有触发限流；
3. **随机一言**：博客友链页底部调用，1.5 年稳定。

更关键的是**站长的服务态度**——我曾在 GitHub 上提过一个 bug，半夜 12 点反馈，第二天早上 9 点就收到修复 commit。这种节奏在商业 API 服务商那里都罕见。

## 平台特点再过一遍

{% image https://cdn.dusays.com/2026/09/889-4.jpg  ratio:1918/866 %}

- **Golang 自研**：平台对技术完全掌控，处理高并发和大流量时响应速度和稳定性都有保障；
- **微服务架构**：每个 API 服务独立运行，轻松应对流量高峰；
- **ICP 备案**：合法合规运营，备案号可查；
- **完全免费**：不收钱、不限速、不限调用次数；
- **完善文档**：提供多语言示例代码和在线调试。

## 关于资源域名的说明

我注意到小小 API 当前**未配置 CDN**，所以大家在调用以下两类资源域时，需要按下面的映射临时替换：

- `v2.dusays.com`（原 API 网关临时映射）
- `images.dusays.com`（原静态资源临时映射）

站长说下一步会统一到自有 CDN，映射会持续到切换完成。**主站域名不变**，访问入口依旧是 [https://xxapi.cn/](https://xxapi.cn/)。
