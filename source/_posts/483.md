> 最近有小伙伴反馈去不图床打开有一些慢，除了网络的问题外，页面处理速度多少也会有些影响，毕竟图床用户越来越多。经朋友推荐，打算用 OpenLiteSpeed 替代 Nginx 以获取性能提升。

<!-- more -->

### 软件简介

OpenLiteSpeed 是 LiteSpeed EnterPrise 的社区版本，其组件由官方进行主要维护和更新，提供商用企业级的体验。在性能方面，LiteSpeed Tech 提供的 BenchMark 显示，在 WordPress/Joomla/OpenCart/ModSecurity 和 HTTP/2 以及小型静态文件的测试中，OpenLiteSpeed 都比 Apache HTTPD 和 Nginx 有更好的表现：

{% image https://cdn.dusays.com/2022/07/483-1.jpg %}

### 注意事项

1. OpenLiteSpeed 兼容 Apache 的伪静态格式，也就是说，可直接读取 .htaccess 文件；

2. OpenLiteSpeed 不支持低版本 PHP，如果您需要 PHP5.6以下版本，则不能使用 OpenLiteSpeed；

3. 请不要为 OpenLiteSpeed 的 PHP 安装 OPcache 扩展，实测表明安装后会降低效率；

4. 相较 Nginx，OpenLiteSpeed 在 PHP 扩展性和可调配置方面略差。
