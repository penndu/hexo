> mount 是 Linux 下的一个命令，它可以将分区挂载到 Linux 的某个目录下，从而将分区与该目录关联起来。我们只要访问这个目录，就相当于访问该分区。今天杜老师为大家讲解 mount 命令的使用！

## 命令选项

选项列表如下：

| 选项 | 作用 |
| - | - |
| -V | 显示程序版本 |
| -h | 显示辅助信息 |
| -v | 显示挂载信息，通常与 -f 配合用于排查错误 |
| -a | 将 /etc/fstab 中定义的所有文件系统挂载 |
| -F | 该选项通常与 -a 配合使用，会为每个 mount 操作派生一个进程执行，在需要挂载大量 NFS 文件系统时可加快挂载速度 |
| -f | 通常用于调试。它会使 mount 不执行实际挂载动作，仅模拟整个挂载过程，通常与 -v 配合使用 |
| -n | 一般而言，mount 挂载后会在 /etc/mtab 中写入一条数据。在系统中没有可写文件系统存在的情况下，可用该选项取消此动作 |
| -r | 等同于 -o ro |
| -w | 等同于 -o rw |
| -L | 挂载带有特定标签的硬盘分区 |
| -U | 卸载带有特定标签的硬盘分区。-L 和 -U 必须在 /proc/partition 等文件存在时才有意义 |
| -t | 指定文件系统类型，通常无需指定，mount 会自动选择正确的类型 |

## 特殊选项

可通过 -o 加上以下选项实现特殊挂载：

| 参数 | 说明 |
| - | - |
| atime/noatime | 更新访问时间/不更新访问时间，访问分区内文件时是否更新文件访问时间，默认更新 |
| async/sync | 异步/同步，默认异步 |
| auto/noauto | 自动/手动，执行 -a 命令时是否自动按 /etc/fstab 内容挂载，默认自动 |
| defaults | 挂载的默认值，相当于 rw、suid、dev、exec、auto、nouser、async 七个选项 |
| exec/noexec | 允许/禁止执行，设定是否允许在该文件系统上执行可执行文件，默认允许 |
| remount | 重新挂载已挂载的文件系统，一般用于临时修改特殊权限 |
| rw/ro | 读写/只读，文件系统挂载后是否具有读写权限，默认读写 |
| suid/nosuid | 具有/不具有 SUID 权限，设定文件系统是否具有 SUID 与 SGID 权限，默认具有 |
| user/nouser | 允许/不允许普通用户挂载，设定文件系统是否允许普通用户挂载，默认不允许，仅 root 可挂载分区 |
| dev/nodev | 是否支持在此文件系统上使用设备文件 |
| loop | 使用 loop 模式将一个文件当作硬盘分区挂载到系统 |
| usrquota/grpquota | 表示文件系统支持用户磁盘配额/群组磁盘配额，默认不支持 |
